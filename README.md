# CrepeCost — คำนวณต้นทุนร้านเครป

เว็บคิดต้นทุนต่อจาน กำไรแต่ละเมนู และจุดคุ้มทุน สำหรับร้านเครปเล็ก ๆ
ไม่ต้องสมัครอะไร ไม่ต้องมีเน็ตก็ใช้ได้ ข้อมูลเก็บอยู่ในเครื่องผู้ใช้เท่านั้น

**เปิดใช้งาน:** https://pramvit18-group.gitlab.io/crepecost/

บน iPhone เปิดด้วย Safari แล้วกดแชร์ → "เพิ่มไปยังโฮมสกรีน" จะได้ไอคอนใช้เหมือนแอป

---

## วิธีใช้

| แท็บ | ทำอะไร |
|---|---|
| **1. วัตถุดิบ** | กรอกตามที่ซื้อจริง (แป้ง 1000 กรัม 45 บาท) ระบบคิดราคาต่อหน่วยให้เอง |
| **2. เมนู / สูตร** | สร้างเมนู ใส่ราคาขาย เลือกว่าใช้วัตถุดิบอะไรกี่กรัม → ได้ต้นทุน กำไร % และราคาที่ควรขาย |
| **3. ต้นทุนคงที่** | ค่าเช่า ค่าไฟ ค่าแก๊ส ค่าแรง → บอกว่าต้องขายวันละกี่จานถึงคุ้ม |
| **4. สรุป** | เทียบทุกเมนู ตัวไหนกำไรดี ตัวไหนควรขึ้นราคา |

เปิดครั้งแรกจะมีข้อมูลตัวอย่างให้ดูก่อน กดปุ่ม "ล้างทิ้ง เริ่มกรอกของร้านเรา" เมื่อพร้อม

## ข้อมูลเก็บที่ไหน

เก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น พิมพ์แล้วบันทึกทันที

⚠️ **ข้อควรรู้**
- ข้อมูลใน**มือถือกับในคอมเป็นคนละชุด** ไม่ซิงก์กัน
- iOS ล้างข้อมูลเว็บที่ไม่ได้เปิดเกิน 7 วัน → ถ้าหยุดใช้ยาวอาจหาย
- ใช้ปุ่ม **สำรอง / กู้คืนข้อมูล** คัดลอกเก็บไว้เป็นระยะ (ส่งเข้าไลน์ตัวเองก็ได้)

อยากให้ซิงก์อัตโนมัติข้ามเครื่องต้องต่อฐานข้อมูลจริง เช่น Supabase

## รันบนเครื่องตัวเอง

```bash
node serve.js          # เปิดที่ http://localhost:8080
```

จะขึ้น URL สำหรับเปิดบนมือถือผ่าน Wi-Fi วงเดียวกันให้ด้วย

```bash
npm run icons          # สร้างไอคอนใหม่ (วาดด้วยโค้ด ไม่มีไฟล์ภาพต้นฉบับ)
npm run build          # รวมไฟล์เว็บเข้า www/ สำหรับ build เป็นแอป
```

## โครงสร้าง

```
index.html               ตัวเว็บทั้งหมด (HTML + CSS + JS ในไฟล์เดียว ไม่มี framework)
manifest.webmanifest     ทำให้ติดตั้งเป็นแอปบนหน้าจอโฮมได้
sw.js                    service worker — เปิดได้ตอนไม่มีเน็ต
icons/                   ไอคอนสำหรับเว็บ
assets/                  ไอคอน 1024px + splash 2732px สำหรับ build เป็นแอป iOS
serve.js                 เซิร์ฟเวอร์เล็ก ๆ ไว้เปิดบนมือถือผ่าน Wi-Fi
tools/make-icons.js      สร้างไฟล์ PNG ทั้งหมดด้วยโค้ด ไม่ใช้ไลบรารีภายนอก
tools/build-www.js       รวมไฟล์เว็บเข้า www/
.gitlab-ci.yml           เอาเว็บขึ้น GitLab Pages อัตโนมัติ
.github/workflows/       สูตร build ไฟล์ .ipa (ต้องใช้ GitHub เพราะต้องการเครื่อง Mac)
```
